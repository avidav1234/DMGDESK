# GENERA MAIN
ctk.CTkButton(
    main_group, 
    text="📝 GENERA MAIN", 
    width=140, height=40,
    command=self._genera_main
).pack(side="left", padx=2)

# IMPOSTAZIONI ⚙️
ctk.CTkButton(
    main_group, 
    text="⚙️", 
    width=45, height=40,
    fg_color="#9E9E9E",
    command=self._apri_impostazioni_calibra
).pack(side="left", padx=2)

#### **C) Funzioni (alla fine della classe):**
```python
def _apri_impostazioni_calibra(self):
    """Apre popup impostazioni."""
    show_calibra_settings(self.parent)

def _genera_main(self):
    """Genera MAIN con CALIBRA ONLY configurabile."""
    if self.main.df.empty:
        messagebox.showwarning("Attenzione", "Nessun utensile")
        return
    
    df_macchina = self.main.df[
        self.main.df['Stato_Utensile'] == 'IN_MACCHINA'
    ].copy()
    
    if df_macchina.empty:
        messagebox.showwarning("Attenzione", "Nessun utensile in macchina")
        return
    
    # GENERA CON PREVIEW
    success, msg = genera_programma_main_with_preview(
        df_macchina, 
        nome_cartella="MAIN",
        parent=self.parent
    )
    
    if success:
        messagebox.showinfo("✅ Successo", msg)
    elif msg not in ["Annullato", "Generazione annullata"]:
        messagebox.showerror("Errore", msg)
```

## 🎯 LE 4 MODALITÀ

### **❌ Mai**
```
Nessun CALIBRA ONLY nel MAIN
```

### **▶️ Solo Inizio**
```
CALIBRA ONLY solo per T1 (primo utensile)
```

### **✨ Finitura**
```
CALIBRA ONLY per ogni utensile FF (frese finitura)

T1 (FF10R0.5L50F60G3)
G65 P9832 T1 ;CALIBRA ONLY    ← FF!
T2 (FS12R1L60F70H8)
T3 (FF8R0.3L40F50G2)
G65 P9832 T3 ;CALIBRA ONLY    ← FF!
```

### **⚡ Avanzato**
```
FF sempre + ogni 3° richiamo dello stesso utensile

T1 (FF10R0.5L50F60G3)
G65 P9832 T1 ;CALIBRA ONLY    ← FF!
T2 (FS12R1L60F70H8)
T3 (FS12R1L60F70H8)            ← 2° richiamo
T4 (FS12R1L60F70H8)
G65 P9832 T4 ;CALIBRA ONLY    ← 3° richiamo!
```
