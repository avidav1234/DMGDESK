#### **C) Funzioni (alla fine classe):**
```python
def _apri_impostazioni_calibra(self):
    show_calibra_settings(self.parent)

def _genera_main(self):
    if self.main.df.empty:
        messagebox.showwarning("Attenzione", "Nessun utensile")
        return
    
    df_macchina = self.main.df[
        self.main.df['Stato_Utensile'] == 'IN_MACCHINA'
    ].copy()
    
    if df_macchina.empty:
        messagebox.showwarning("Attenzione", "Nessun utensile in macchina")
        return
    
    success, msg = genera_programma_main_with_preview(
        df_macchina, "MAIN", parent=self.parent
    )
    
    if success:
        messagebox.showinfo("✅ Successo", msg)
    elif msg not in ["Annullato", "Generazione annullata"]:
        messagebox.showerror("Errore", msg)
```

## 🎯 LE 4 MODALITÀ

| Modalità | Icona | Comportamento |
|----------|-------|---------------|
| **Mai** | ❌ | Nessun CALIBRA ONLY |
| **Solo Inizio** | ▶️ | Solo T1 (primo utensile) |
| **Finitura** | ✨ | Ogni FF (frese finitura) |
| **Avanzato** | ⚡ | FF + ogni 3° richiamo |
