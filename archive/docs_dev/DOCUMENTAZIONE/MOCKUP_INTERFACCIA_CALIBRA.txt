### **4. FILE MAIN GENERATO**

#### **Modalità: ✨ Finitura**

```gcode
; PROGRAMMA MAIN O9999 - MAIN
; Generato: 2025-12-26 11:30
; Utensili: 12
; CALIBRA ONLY: ✨ Tutti gli utensili FF
%
O9999
;
T1 (FF10R0.5L50F60G3)
G65 P9832 T1 ;CALIBRA ONLY    ← FF, quindi calibra!
T2 (FS12R1L60F70H8)            ← FS, niente calibra
T3 (P10-30VDF60E3)             ← P, niente calibra
T4 (FF8R0.3L40F50G2)
G65 P9832 T4 ;CALIBRA ONLY    ← FF, quindi calibra!
T5 (FS12R1L60F70H8)            ← FS, niente calibra
T6 (PI8-25VDF55G2)             ← PI, niente calibra
T7 (FF6R0.2L35F45G1)
G65 P9832 T7 ;CALIBRA ONLY    ← FF, quindi calibra!
T8 (R60R2L10F80H10)            ← R, niente calibra
T9 (D100R3L5F90H12)            ← D, niente calibra
T10 (FF12R0.8L55F65G3)
G65 P9832 T10 ;CALIBRA ONLY   ← FF, quindi calibra!
T11 (SMS10X90F60H8)            ← SMS, niente calibra
T12 (FS15R1.2L70F75H9)         ← FS, niente calibra
;
M30
%
```

**4 utensili FF → 4 CALIBRA ONLY! ✅**

## 📝 CLASSIFICAZIONE UTENSILI

```
FINITURA (FF):
✅ FF10R0.5L50F60G3
✅ FFHSC12R1L60F70E2
✅ FFPI8R0.3L40F50G1
✅ FF6R0.2L35F45G1

SGROSATURA (tutto il resto):
❌ FS12R1L60F70H8     (Fresa Sgrosso)
❌ FSHSC10R0.8L55F65  (Fresa Sgrosso HSC)
❌ P10-30VDF60E3      (Punta)
❌ PI8-25VDF55G2      (Punta Integrale)
❌ R60R2L10F80H10     (Coda Rondine)
❌ D100R3L5F90H12     (Disco)
❌ SMS10X90F60H8      (Smussatore)
❌ C20X45F70H6        (Caletto)
```

**Logica:** Solo gli utensili che iniziano con `FF` sono finitura.
